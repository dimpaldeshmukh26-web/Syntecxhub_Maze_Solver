Maze Solver using A* Search Algorithm

Project Description

This project solves a maze using the A* Search Algorithm to find the shortest path from the start point to the goal.

Algorithm

A* Search Algorithm

Features

- Represents the maze using a grid.
- Identifies the start and goal positions.
- Finds the shortest path while avoiding walls.
- Displays the maze and the calculated path in the terminal.
- Handles cases where no path is available.

Symbols

- S: Start position
- G: Goal position
- *: Path
- #: Wall
- .: Free space

Programming Language

Python
